Do not mention F-1 OPT status, EAD timing, hourly-vs-piece-rate visa compliance structure, or any other visa logistics in a first-contact or early-stage reply to a recruiter. Draft outreach around technical fit and interest only.

**Why:** Justin's call on the Mercor/Hrishi Vora thread — he wants to build some rapport and get through interviews first, then bring up visa/OPT structuring questions once there is real momentum, rather than opening with a compliance question that could cause a recruiter to pass early. See [[project_ead_clock]] for his actual EAD timing, and [[feedback_outreach_style_rules]] / [[feedback_outreach_research]] for general outreach tone rules this doesn't override.

**How to apply:** When drafting any reply to inbound recruiter contact (job-automator Sub-workflow C or ad hoc), leave OPT/visa/sponsorship content out by default. Only raise it when: (a) the user explicitly asks to include it, (b) an offer or formal engagement structure is being discussed, or (c) the user says interviews are done / it's time to raise it. If a job-fit-analysis constraint flag (sponsorship, EAD pending) would normally surface a caution, still report it to the user in chat — this rule is about what goes into the outward-facing draft, not about hiding it from Justin.
